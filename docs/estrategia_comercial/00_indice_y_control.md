## Cómo leer este expediente

Cada afirmación relevante se clasifica como:

- **DV — Dato verificado:** fuente externa identificada y fecha de consulta.
- **HS — Hallazgo del sistema:** comprobado en código, interfaz o documentación técnica.
- **T — Testimonio:** declaración del equipo o cliente identificado.
- **I — Inferencia:** conclusión razonada; no debe presentarse como hecho.
- **H — Hipótesis:** debe probarse en campo.
- **P — Provisional:** decisión utilizable mientras se obtiene información faltante.

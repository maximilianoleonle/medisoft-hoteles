# Etapa 5 — Segmentación y mercado meta

## Mercado meta inicial recomendado

**Hoteles independientes de aproximadamente 6 a 40 habitaciones, accesibles en Juquila, donde reservaciones, estados de habitación y control de turno dependan total o parcialmente de libreta, Excel o mensajes; con dueño/administrador local, internet utilizable y disposición para capacitar al personal.** **P/H.**

El tamaño es provisional: no existe aún evidencia de campo para fijar un corte exacto.

## Segmentos conductuales

### A. Libreta operativa

- Dolor: búsqueda, traspaso de turno, disponibilidad y trazabilidad.
- Entrada: base.
- Mensaje: pasar a un control organizado con acompañamiento.
- Prioridad: alta si el dueño reconoce errores o falta de visibilidad.

### B. Excel fragmentado

- Dolor: archivos separados, doble captura y dependencia de una persona.
- Entrada: base + opcional según problema.
- Mensaje: conectar operación, no desacreditar Excel.
- Prioridad: alta.

### C. Sistema insatisfactorio

- Dolor: soporte, complejidad, precio o falta de ajuste.
- Entrada: diagnóstico y migración.
- Prioridad: media; el cambio tiene mayor riesgo y comparación funcional.

### D. Sistema satisfactorio

- No perseguir activamente.
- Mantener contacto solo si surge un problema claro.

### E. Negocio demasiado informal o sin condiciones

- Sin dispositivo/internet, sin responsable de captura o sin voluntad de cambio.
- No apto ahora; registrar para nutrición futura.

## Matriz de priorización

Puntuar 0–3:
| Variable | 0 | 3 |
|---|---|---|
| Problema reconocido | Ninguno | Frecuente y costoso |
| Urgencia | “Algún día” | Necesita resolver ahora |
| Acceso al decisor | Imposible | Conversación directa |
| Ajuste funcional | Requiere desarrollo | Base actual resuelve |
| Adopción | Resistencia total | Responsable comprometido |
| Infraestructura | No existe | Lista |
| Referencia local relevante | Ninguna | Caso muy semejante |

- 16–21: prioridad A.
- 11–15: prioridad B.
- 0–10: nutrir o descartar.

## Mercado no recomendable

- exige channel manager/OTA como condición inmediata;
- requiere timbrado CFDI dentro de Medisoft;
- necesita operación offline garantizada;
- solicita personalización crítica antes de comprar;
- no ofrece acceso al decisor;
- quiere piloto sin fecha, responsable ni intención de evaluar;
- busca precio mínimo y soporte ilimitado;
- trata datos sin aceptar condiciones mínimas de seguridad.

## Orden territorial

1. Cabecera de Santa Catarina Juquila.
2. Prospectos por referencia de San Nicolás/Los Cedros.
3. Localidades de la ruta solo cuando exista concentración suficiente o visita agendada.
4. Oaxaca capital después de validar mensaje, onboarding y soporte.

## Hipótesis a validar

1. El segmento libreta/Excel tendrá menor barrera competitiva.
2. El dueño local acortará el ciclo de decisión.
3. La referencia de un hotel de Juquila reducirá la desconfianza.
4. El problema de turno/ocupación será más urgente que los módulos opcionales.
5. Un hotel con más habitaciones podría pagar más, pero también exigir integraciones ausentes.
